Setting Up G-Stop

The Gurdjieff "Stop!" exercise as an Android app that plays the part of the teacher for solo practice.

Install it

G-Stop is a private Android app (sideloading), not yet on the Play Store. You will need to set Android's install unknown apps permission, which is asked for at the moment you install and which you can revoke afterwards.

First, install Obtainium, which is like an app store for private apps:

Download & Install Obtainium from its official repo: github.com/ImranR98/Obtainium

Then, come back here and tap:

Add G-Stop to Obtainium

Obtainium shows the G-Stop configuration it's about to add. Confirm it, tap Install, and allow Obtainium to install unknown apps when Android asks.

The install is done!

Don't want Obtainium? Download the G-Stop APK straight from the releases page and open it. Same app — you'll just have to check the G-Stop Github repo yourself for new versions.

Grant permissions to enable G-Stops

Open the G-Stop app. The main screen shows a card for anything the system is withholding, each with a button that opens the right settings page. Clear all of them:

  • Alarms & reminders — without it, stops arrive late or not at all
  • Notifications — so a stop can take over a locked screen
  • Battery optimisation exemption — so the schedule survives deep idle
  • Do Not Disturb access — optional; lets the volume floor work while DND is on

You're all set and ready for Stops when the screen reads “Supersession checks passed.”

After each Stop, you have 5 minutes to record Observation notes about how you were Moving, Feeling, and Thinking, to aid with your Work.

Tweak the G-Stop settings as you prefer

Default settings: 2 to 5 stops a day, each lasting between 20s & 2m, never less than forty-five minutes apart, and nothing between 23:00 and 07:00.

  • Long-press during a stop to suppress it — for driving, stairs, anything where freezing would be dangerous.
  • Pause G-Stop on the main screen (or the widget) for longer stretches when stops wouldn't be welcome.
  • Set a backup folder in Settings to save your Stops long-term.

Optional Widget

Put a G-Stop widget on your phone's home screen for easy pause / resume

Find the widget in your phone's regular widgets menu.

  • One tap pauses the practice or resumes it.
  • Two quick taps open the G-Stop app.

Privacy Note

Everything stays on your phone. There's no account, no server, no telemetry, and the app doesn't even use internet permissions.
